# EJAZ Transport — Official 3D Vehicle Models
This directory stores the official GLB / GLTF 3D model files for the 4 canonical fleet categories:
1. FLATBED = سطحة (/models/trucks/flatbed.glb)
2. REFRIGERATED = براد (/models/trucks/refrigerated.glb)
3. DRY_VAN = جاف (/models/trucks/dry.glb)
4. CURTAINSIDER = ستارة (/models/trucks/curtainsider.glb)

The Vehicle3DViewer automatically loads these GLB models if present, or falls back to the high-detail procedural Mercedes-Benz Actros 3D model.
