## ٢ · انعدام التدرج العمقي (Elevation) — السبب الأول لمظهر «المسطّح»

`src/index.css:247-251`:

```css
.card {
  background-color: var(--color-surface-3);
  border-radius: 8px;
  box-shadow: inset 0 0 0 1px color-mix(in oklab, var(--color-border-subtle) 70%, transparent);
}
```

الظل **داخلي فقط** (`inset`) — أي خط حدودي، لا ظل سقوط إطلاقًا.

ومقياس الظلال المعرَّف `--ds-shadow-sm/md/lg/xl` (٤ مستويات، ومُعاد ضبطه للثيم الفاتح في `index.css:172-175`) مستخدم **صفر مرة في `.tsx`**، ومرة واحدة في `.glass`.

ولأن `.card` لا تعطي عمقًا، يبني المطوّر أسطحه يدويًا: **٤١٠ استخدامًا** لـ `bg-surface-N` مقابل **٥٣ استخدامًا** فقط لفئة `.card`.

| `bg-surface-2` | 183 | | `bg-surface-0` | 27 |
| `bg-surface-1` | 75 | | `bg-surface-5` | 21 |
| `bg-surface-3` | 58 | | `bg-surface-6` | 3 |

## ٥ · الشريط الجانبي: ٢٣ مدخلًا في عرض ٢٦٤ بكسل

`Sidebar.tsx` — ١٥ عنصر تنقّل علويًا:

```
overview · operations · trips · shipments · fleet · vehicle-assets ·
drivers · registrations · tracking · reports · alerts · chats ·
branding · ai · history
```

يضاف إليها مجموعتان قابلتان للطي: **الطلبات** (٥ عناصر فرعية) و**التحليلات** (٣ عناصر فرعية) = **٢٣ مدخلًا** إجمالًا.

**ثلاث مشكلات بنيوية:**

1. **العناصر الثلاثة تحت «التحليلات» تصل كلها إلى نفس الوجهة.** `Sidebar.tsx:169` — التسميات الثلاث («نسبة الاستغلال» / «استهلاك الوقود» / «نسبة الالتزام بالوقت») تستدعي جميعها `onSelect("analysis")`. ثلاثة مداخل لا تتصرف بثلاث طرق مختلفة = كسر لتوقع المستخدم.

2. **عناصر تفتح نوافذ منبثقة تبدو كعناصر تنقّل.** `alerts` و`ai` و`branding` تُعالَج في `WebConsole.tsx` عبر `handleNavSelect` بفتح نافذة (`setShowAIModal(true)` إلخ) لا بتغيير الصفحة — لكنها تُرسم بنفس `row()` تمامًا. لا مؤشر بصري يفرّق «ينقلني» عن «يفتح نافذة».

3. **تكرار وجهات.** العناصر الفرعية `trucks` / `cargos` / `repair` تصل إلى نفس شاشات `fleet` / `shipments` العلوية.

## ٦ · شريط «الإنشاء السريع» مخفي عن مستخدمي اللمس نهائيًا

`Sidebar.tsx:184`:

```jsx
<div className="pointer-events-none absolute -top-9 inset-x-0 flex justify-center
                opacity-0 transition-all duration-300
                group-hover:pointer-events-auto group-hover:-top-11 group-hover:opacity-100">
```

خمسة أزرار إنشاء سريع (شاحنة · شحنة · صيانة · سائق · تقرير) لا تظهر إلا عند `group-hover`.

لا يوجد `group-focus-within:` ولا `group-focus-visible:` ولا أي بديل للمس. `index.css:217-232` يوسّع منطقة اللمس لأزرار `.btn-icon-sm` إلى ٤٤ بكسل (`width: max(100%, 44px)`) — لكن هذا الشريط **لا يصل إليه مستخدم اللمس أصلًا** ليضغط عليه.

**النتيجة:** على الجوال (حيث الشريط الجانبي درج) الميزة غير موجودة عمليًا.
