# المتابعة الدورية لفرع التطوير

هذه الأدوات تُبقي فرع الجلسة `arena/e25f790d-repo` متزامنًا تلقائيًا مع فرع التطوير
المتتبَّع (افتراضيًا `redesign/ejaz-reality-command-center`)، وتُبلّغ عن كل دورة.

## التشغيل

```bash
npm run sync:branch    # دورة واحدة الآن
npm run sync:watch     # متابعة دورية مستمرة (كل 5 دقائق افتراضيًا)
npm run sync:status    # تقرير آخر دورة بصيغة مقروءة
```

## ماذا تفعل الدورة بالضبط؟

1. **تتحقق من الفرع والشجرة** — لا تعمل إلا على فرع الجلسة، وإن وُجدت تعديلات غير
   محفوظة تتوقف بحالة `blocked` بدل أن تدمج فوق عملك.
2. **تجلب** آخر ما نزل على الفرع المتتبَّع: `git fetch origin +refs/heads/<branch>:refs/remotes/all/<branch>`.
3. **تحسب الجديد** — إن لم يوجد شيء تنتهي بحالة `up-to-date` بدون أي تغيير.
4. **تدمج** بـ `git merge --no-ff` (تاريخ واضح لكل مزامنة).
5. **تُثبّت الحزم** عند تغيّر `package.json` أو `package-lock.json` فقط.
6. **تُصلح مقياس التصميم تلقائيًا** — إن كتب الفرع أدوات Tailwind افتراضية
   (`text-sm` / `rounded-3xl` / `sm:text-4xl`) يشغّل المشروع كودمود
   `scripts/migrate-design-tokens.mjs` ويحفظ النتيجة في كوميت مستقل
   `chore(sync): fold design tokens…` (هذا أكثر ما كان يُحمرّ CI بعد كل اندماج).
7. **تفحص الأنواع** بـ `npx tsc --noEmit`، وتشغّل الاختبارات إن طلبت ذلك.
8. **تدفع** فرع الجلسة إلى GitHub بعد نجاح فحص الأنواع فقط.

## الحالات

| الحالة | المعنى |
| --- | --- |
| `up-to-date` | لا جديد على الفرع المتتبَّع |
| `synced` | تم الدمج والدفع بنجاح |
| `attention` | تم الدمج لكن فحص الأنواع أو الاختبارات أو الدفع يحتاج نظرة |
| `conflict` | تعارض لم يُحسم، أو حُسم ثم فشل فحص الأنواع/الاختبارات فأُرجع الفرع كما كان |
| `blocked` | تعديلات غير محفوظة في الشجرة |
| `error` | فشل جلب/تثبيت/فرع غير صحيح |

## الإعدادات (متغيرات بيئة)

| المتغير | الافتراضي | الوظيفة |
| --- | --- | --- |
| `TRACK_BRANCH` | `redesign/ejaz-reality-command-center` | الفرع الذي تتابعه |
| `SYNC_INTERVAL_SECONDS` | `300` | الفترة بين الدورات في وضع المراقبة |
| `RUN_TESTS` | `0` | `1` لتشغيل `npm test` في كل دورة |
| `SYNC_PUSH` | `1` | `0` لإيقاف الدفع |
| `SYNC_INSTALL` | `1` | `0` لإيقاف `npm install` |
| `SYNC_AUTOFIX` | `1` | `0` لإيقاف الطيّ التلقائي لمقياس التصميم |
| `SYNC_CONFLICT_STRATEGY` | `theirs` | `abort` لإلغاء الدمج عند أي تعارض بدل حسمه لصالح الفرع |
| `SESSION_BRANCH` | `arena/e25f790d-repo` | فرع الوجهة |

مثال لمتابعة فرع آخر كل دقيقتين:

```bash
TRACK_BRANCH=redesign/ejaz-3d-rebuild SYNC_INTERVAL_SECONDS=120 npm run sync:watch
```

## السجلّات

- `.sync/status.json` — تقرير آخر دورة (منظَّم، يقرأه `npm run sync:status`).
- `.sync/sync.log` — سجل زمني لكل الدورات.

المجلد `.sync/` مستثنى من Git لأن محتواه بيانات تشغيل.

## ملاحظات

- عند التعارض: تُؤخذ نسخة الفرع المتتبَّع للملفات المتعارضة (الاستراتيجية `theirs`)،
  ثم يُعاد الطيّ والتحقق؛ ولا يُدفع شيء قبل نجاح فحص الأنواع والاختبارات، وإن فشلا
  يُرجَع الفرع بالكامل إلى ما قبل الدمج (`git reset --hard`).
- المزامنة **لا** تستخدم `git push --force` ولا تحذف شيئًا؛ عند أي تعارض تتوقف
  وتحتفظ بفرعك الحالي كما هو.
- إن تغيّرت الحزم، أعد تشغيل سيرفر التطوير (`npm run dev`) لالتقاط التبعيات الجديدة.
- المتابعة الدورية تعمل طالما العملية حيّة؛ عند إغلاق البيئة أعد تشغيلها بالأمر أعلاه.
